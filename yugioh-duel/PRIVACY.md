# Fivefold Arc Duel — Privacy for the Private Test

## What the app stores

- A display name for each claimed Duelist seat.
- The current Duel and Match state: Life Points, phase, Match score, declared outcome, and the Life Point correction record.
- Shared table utilities and notes when those features are enabled.
- A server-side hash of each phone's private reclaim credential. The raw credential stays only on that phone.

## What the app does not need

- An account, email address, deck list, card collection, contacts, precise location, payment data, or access to another game client.
- Browser changes made while offline. The app shows only the last confirmed state and does not queue tabletop actions for later replay.

## Before public availability

The hosted privacy page must name the storage provider, retention period, deletion route, and contact method. Do not represent this private-test statement as a complete public privacy policy.
